# Maintained sources and provider placement

Thirteen focused packages are maintained in `docs/skills/workhunt-*`, including `workhunt-maintain-sources`. Four runtime packages live in `skills/`: `workhunt-search`, `workhunt-cv`, `workhunt-apply`, and `workhunt-configure-profile`. All seventeen are registered in the unified installer.

Shared authorities are `templates/`, `JOB_SEARCH_PLAYBOOK.md`, `docs/skills/WORKHUNT_CONTEXT.md`, `docs/skills/JOB_TRACKING.md`, and the 28-source catalog. Refresh copies only generic authorities and empty templates into canonical package assets/references. It then invokes the unified packaging contract for `.agents/skills`, `.claude/skills` and `.kiro/skills`. Generated Markdown links and workspace pointers may intentionally differ from raw canonical files; verify against `package()` output, not raw-directory equality.

`tools/install_workhunt_skills.py --project PATH` installs project providers; with no destination it uses this checkout. `--home PATH` explicitly selects an isolated/personal home and adds `.gemini/config/skills`. It never chooses a user home implicitly. All destinations are preflighted before mutation, unrelated files are retained, and unowned or modified conflicts stop the whole installation. `--check` validates expected content without writes. Manifest ownership is checked before adoption, including when a customized file is committed or happens to equal a new generated version. Git tracking alone never authorizes replacement. Without a manifest only exact known canonical/generated bytes can be adopted.

Every generated package has a portable `workspace.json` with no machine binding and `scripts/resolve_workspace.py`. Resolution precedence is explicit shared root, current checkout/ancestors, then private `workspace.local.json`. A release root is recognized by shared context plus templates, without requiring a profile. `--workspace PATH` creates local bindings only in the explicitly selected installation; these private descriptors are ignored and excluded from distribution. Shared root and private `.workhunt` root are separate.

Completed CV/profile/manifest/history/output records always stay private. Install and refresh never read them into packages. Isolated installation tests establish file placement and helper resolution, not provider-application discovery or personal account integration.
