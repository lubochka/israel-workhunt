# Curate portfolio evidence workflow

Establish audience and evidence need, then inspect only supplied or authorized materials. Rank relevant samples by demonstrated capability, not popularity. Separate personal, team, upstream and AI-assisted contributions, implemented state and verified state. Record source/version/scenario/date, factual claims, unresolved evidence and sharing restrictions. Draft a case study connecting a business workflow, personal decisions, alternatives and a meaningful failure case. A demo storyboard remains a plan unless actually run under separate authorization. Connect exact samples to requested job/project requirements without double-counting them. Metadata or pinning suggestions remain proposals. No code edits, tests, benchmarks, screenshots, demos, uploads or publication are authorized by curation.
