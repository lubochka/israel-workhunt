# Plan the search

Read the private profile/evidence ledger and `docs/skills/WORKHUNT_CONTEXT.md` in the selected workspace. The latter is a project reference; installed packages carry a shared copy in `references/context.md`. Use `references/playbook.md` and `references/tracking.md` when installed outside the repository. Do not infer candidate criteria from this package. Preserve user scope, privacy, uncertainty and actual evidence. Use public read-only sources or isolated hidden browsing; no personal desktop, tabs, profile or credentials.


Read [workflow](references/workflow.md) for this task, then use [record](assets/record.md) for the requested local output. Keep completed records in `.workhunt/`. Do not count this template as a completed check.

Apply the current private country/work-path policy independently of saved freshness. Unknown or conflicting exact-opportunity eligibility cannot qualify; no remote label, CV location or saved policy grants legal status or execution authority.

Read [manual discovery](references/MANUAL_DISCOVERY.md) and the shared 28-source catalog: the original 23 IDs and evidence remain, with Arc, Hacker News, Scalable Path, X-Team and Gun.io added and Guru enriched. Select routes using current candidate settings and the active request. Offline `discovery_routes.py` resolves aliases for source planning only; it neither fetches nor updates health. Generic intake does not count as an opportunity; exact agency vacancy screening remains eligible for the normal checks. A reviewed or attached request template does not invoke a search.
