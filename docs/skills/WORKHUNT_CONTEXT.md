# Shared Workhunt context

This release has no candidate profile. Read `.workhunt/profile.json` and `.workhunt/profile-evidence.json` in the user's explicitly selected workspace. Use [profile setup](../../skills/workhunt-configure-profile/SKILL.md) if they are absent or unconfigured. Unknown facts and preferences block dependent actions only; do not infer them from examples.

[The playbook](../../JOB_SEARCH_PLAYBOOK.md) and [tracking contract](JOB_TRACKING.md) apply to all focused skills. Preserve the exact 75% fit calculation, fixed 24-hour publication/refresh window, route identity, country eligibility, history and submission evidence. Result language and candidate criteria come from private settings. The current request controls scope and destination; shared guidance is not authorization to act externally.

Keep actual CVs, extracts, completed drafts and history out of provider packages. Sources are public read-only tools or isolated hidden/headless sessions; never personal browser profiles or desktop control. Retain factual unknowns and disagreements, and report only observed results.
