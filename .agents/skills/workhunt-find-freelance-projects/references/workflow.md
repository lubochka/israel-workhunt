# Find paid projects workflow

Read `sources/opportunity-sources.json` or the installed `references/opportunity-sources.json`. Keep all 23 source identities available; select using explicit preferences and access. Distinguish a specific client brief from talent admission, matching networks, inbound profiles, seller services and employment. A generic network page, completed portfolio or seller gig cannot fill the opportunity count. Preserve authentication, fee, proposal-token, payment and country restrictions without enrolling or buying access. Check requested deliverables, mandatory experience, geography/time zone/language, budget/currency/basis, deadline and visible client facts. Unknown commercial terms remain unresolved; a high budget cannot override a conflict. Pass exact opportunities to fit/date/route/history checks. No bid, connection, subscription, client message or API execution without separate scope.
