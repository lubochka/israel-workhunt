# Check freshness workflow

Fix the requested rolling 24-hour start/end in the configured time zone. Record original publication, update/repost, feed/alert availability, first discovery, deadline and verification as distinct events with raw text, source URL and precision. Original publication OR a genuine evidenced refresh/repost inside the window can qualify. An older original date does not cancel a recent valid refresh. Discovery/crawl/check time and malformed relative labels do not qualify. Date-only or relative evidence needs its whole supported interval inside the window; never invent an hour. Preserve contradictory or future-dated evidence as unresolved. Source-specific semantics apply only to the observed channel. Reposts retain identity and exclusions. A proposed check is not a live observation; no schedule or API run is implicit.
