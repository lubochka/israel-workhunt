Show exact title/ID, listing and response URL/navigation, city/country, work mode, country eligibility, fit M/N/percentage/gaps, qualifying publication/refresh and route-check time. State actual count and shortfall against the requested minimum without weakening gates. Use the configured output language. In a requested CV-fit reassessment, show every above-threshold opportunity and its separate remaining shortlist blocker. Write requested platform-specific drafts using supported facts only and label `Draft — not sent`; do not invent attachments, rates, availability or fields. Absent message fields and login-hidden fields must be described accurately. Excluded/stale recommendations get no letter unless separately requested as clarification outside the count. An established authorized notification run can be silent at zero; a manual search receives an honest result. Cards belong in the requested chat, with JSON secondary. No application or external delivery is implied.
