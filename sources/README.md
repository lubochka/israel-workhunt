# Source references

`opportunity-sources.json` preserves the original 23 source IDs within the expanded 28-entry catalog and source-specific access, authentication, freshness, retention, fee and eligibility limitations. Historical observations are dated 2026-11-25 and 2026-11-26 and are not live verification for this release. No provider is default-enabled. Candidate-specific ranking and example queries were removed.

Choose search queries and provider access from the private profile. Never create credentials, connect accounts, pay fees, schedule polling or send proposals from this catalog alone. An access/admission page is not a specific opportunity.

The repository includes the public [288-board employer snapshot and attribution record](upstream/israel-job-search/README.md) from Itai Ahiraz's [israel-job-search](https://github.com/ahiraz/israel-job-search), pinned to revision `7e3a2a8a21c7bea967ddccf6812163ee45adc2f2`, with its unchanged MIT notice. The [detailed contribution map](../THIRD_PARTY_NOTICES.md#itai-ahiraz-and-israel-job-search) credits the directory, provider integration reference, employer-board plus Techmap workflow, source maintenance, and merged discovery results.

A sanitized shared seed is available in `sources/employer-boards.json`; it contains uniform imported defaults and unverified health. Active private registry updates, local overrides, and observed health belong in `.workhunt/sources/`. The importer retains upstream provenance and its MIT notice; saving an import requires `--apply` and does not scan employers. Public identifiers and provider API contracts are not candidate facts. Candidate registry choices, Techmap job data, and private feed links are not bundled. Source switches remain disabled until explicitly configured.

The maintained opportunity catalog now has 28 entries, preserving the original 23 identities and evidence. Arc, HN, Scalable Path, X-Team and Gun.io are manual routes; Guru retains its historical API-documentation 403 alongside scoped project/quote observations. Public source pages are not verified opportunities. The 288-board employer snapshot and shared seed remain unchanged.

Resolve the current explicit request into one complete brief with fixed anchor/windows, minimum/cap and source selection. That resolved brief governs the run; configured preferences fill unspecified new-run settings only. Saved bounds, collector isolation and current private location checks retain their separate contracts. Attaching or reviewing the generic search-request template never invokes it.

See [manual discovery](MANUAL_DISCOVERY.md) and `manual-discovery.json` for lifecycle references and bounded employer recovery. Shared source observations are historical reference evidence, not candidate health or current vacancy verification.
