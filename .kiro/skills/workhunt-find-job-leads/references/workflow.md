# Find employment leads workflow

Read both private history files first. Build queries from explicit profile roles/capabilities and geographic eligibility. Preserve hands-on leadership and systems-analysis tracks when configured; do not remove them through generic title filters. Search independent relevant sources within authorization, read exact listings, retain title/ID/employer, original URL, discovery time and evidence. Treat feed dates and API availability as discovery evidence only. Exclude exact historical suppressions and investigate supplier cross-posts. Route each lead through fit, freshness, application-route and history checks before calling it a recommendation. Record source failures without claiming closure. No application, CV change, account access or monitoring.
