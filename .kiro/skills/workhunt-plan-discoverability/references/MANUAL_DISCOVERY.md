# Selected manual discovery channels and recovery routes

The canonical `opportunity-sources.json` now contains 28 sources: the original 23 identities/evidence plus Arc, Hacker News, Scalable Path, X-Team and Gun.io. Guru is an enriched existing entry. Read the current inventory rather than hard-coding counts. These additions are manual research routes, not new API collectors. `manual-discovery.json` holds supplemental lifecycle references and employer-page recovery evidence; it does not replace the employer registry or its overrides/health.

During an authorized search, select relevant lanes through the maintained catalog and this guide. For offline planning/validation, `python skills/workhunt-search/scripts/discovery_routes.py WORKSPACE --source Arc --source CodementorX` returns one canonical source and its actual routes without network access. `--observation FILE` classifies supplied coverage and lists bounded alternatives; it does not execute them. This resolver is for an authorized local planning/implementation task; a search-only/no-code prompt can read the same JSON directly.

Platform admission, business/payout setup, exact role country/work-path eligibility, and working hours are four separate questions. Apply current private `work_location_policy` and exact ad/form evidence to every opportunity. Publisher nationality, remote/freelance wording or a timezone match cannot clear it. Explicitly selected exclusion conditions apply to supported mandatory requirements; sponsorship does not remove a visa requirement. Unknown eligibility stays outside recommendations. No legal status is inferred.

## Bounded recovery from access failures

Record URL, method, observation time, query/category/page scope and exact failure first. Try each documented public alternative once: normal public page/search, then a fresh agent-owned hidden browser for a JS shell or extractor error, then official employer career page/exact requisition search. A genuinely new tool or authoritative URL is a distinct fallback; repeating an unchanged failing request is not progress. Respect 403/auth, rate limits and access controls; never use personal cookies, credentials, logins or a guessed private endpoint. After these routes, mark the remaining scope blocked/partial and continue other sources.

`checked_empty` requires an explicit empty message for the selected completed scope, with no contrary observed roles and no remaining pages. A successful HTTP response, `Total lines: N`, JavaScript shell, blank iframe, generic login, category-specific empty message or 403/404 does not establish zero jobs. Store `observed_count` separately from coverage completeness. Source-page recovery does not prove any exact vacancy, application form, freshness or fit and never updates collector health.

## Source lifecycle without opportunity duplication

Aliases identify the same source only with explicit rebrand evidence. They never merge job IDs, fresh dates or applications. Acquisitions/shared ownership are relationships, not automatic aliases. `lifecycle_state`, `source_relationships`, evidence URL/date and `review_reason` retain why a route moved or is conditional. Resolve ambiguous aliases as errors; don't pick arbitrarily. Unknown transitions remain unresolved. Recheck these facts when used.

- [CodementorX became Arc](https://arc.dev/w/codementorx). Codementor mentoring remains separate; no blanket Codementor alias.
- [AngelList Talent became Wellfound](https://wellfound.com/blog/angellist-talent-is-now-wellfound); AngelList Venture is not this alias. This is metadata, not an additional selected source.
- [Adeva was acquired by Toptal](https://www.toptal.com/press-center/toptal-announces-acquisition-of-adeva) on 2026-05-26. [Adeva's current page](https://www.toptal.com/adeva) does not prove all intake/project identities are identical. Ownership link only.
- [Worksome for talent](https://www.worksome.com/for-talent) describes private client pools/invitations and general signup ending in 2023. Keep it out of an open-project queue. It is lifecycle context, not a newly adopted search channel.
